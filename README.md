# Coindecc-Pay
**CoindeccPay** is a decentralized, USDC-native payment gateway and routing infrastructure built to solve practical merchant checkout friction onchain. It enables seamless, low-cost merchant settlements and efficient payment flows designed for real-world financial commerce.
## 🚀 Overview
Traditional payment gateways impose high interchange fees and complex cross-border settlement delays. Coindecc Pay leverages modern stablecoin architecture to bring instant, secure, and developer-friendly payment routing to digital and physical merchants.
## 🏗️ Technical Architecture
Smart Contract Deployment: Deployed on Arc Testnet at `0xbD13692792b8356c142c93Ef5B114166e4Cd2Acd`.
**Frontend:** Built with a high-performance React/TypeScript stack via Lovable, integrated with modern multi-wallet frameworks (RainbowKit, Wagmi, viem).
**Payment Rails:** Native USDC routing, optimized gas mechanics, and automated merchant payout allocation.
# 📂 Repository Structure
* `/contracts` - Solidity smart contracts, interfaces, and deployment scripts.
* `/frontend` - User interface, checkout widget components, and merchant dashboard logic.
* `/docs` - Architecture diagrams, API specs, and integration guides.

## 🛠️ Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/coindeccpay/coindecc-pay.git
```
2. Install dependencies:
   ```bash
   cd coindecc-pay/frontend
   npm install
3. Run the development environment:
   ```bash
   npm run dev
```
